# Write formatted content

Use the formatting bar when writing asset descriptions, release notes, blog posts,
profile content, board descriptions, proposals, comments, and other long-form
content. Formatting appears in the editor as you write.

1. Select text, then choose **Bold**, **Italic**, or **Insert link**. With no
   selection, the button inserts an editable starting point.
2. Place the cursor on a line and choose **Heading 1**, or select several lines
   and choose **Bulleted list**.
3. Choose **Source** to edit the underlying Markdown directly. Choose it again
   to return to the formatted view. Your text is not converted to HTML when
   switching modes.

The saved content remains Markdown, and the published page uses the site's
sanitized Markdown renderer. A field's character limit still applies in both
views. Source mode is useful when you need exact Markdown syntax or want to
inspect a link before publishing.

The Notion card editor starts in Source mode to preserve advanced blocks and
continues to accept dropped or pasted image uploads. Board card editing keeps
its existing rich-text and image-upload controls. Plain-text fields such as
names, short descriptions, addresses, and private notes are unchanged.
